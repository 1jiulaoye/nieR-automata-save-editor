四步上手

QUICK START

先备份存档

存档在 文档\My Games\NieR_Automata\，把 SlotData_0.dat 复制一份再动手。

打开文件

运行程序，点「打开存档」，选中要改的 SlotData_#.dat。

改数据

金币页输数字或点 MAX；道具页增删；芯片页换等级。改动会即时预览。

保存回游戏

点「保存」写回文件，切回游戏或重新读档，改动立刻生效。

常见问题

FAQ
改完进游戏没变化？

确认改的是 SlotData_#.dat 而不是 GameData.dat；游戏内数据有缓存，先存一次档再读回来即可。

会被封号吗？

《尼尔：机械纪元》是单机游戏，没有反作弊，改存档不会被封。用修改前建议先手动通关一遍，别把体验一次改没了。

支持哪些版本？

Steam 版、Microsoft Store / Game Pass 版都可以，理论上所有 PC 版通用。

要装 Python 吗？

不用。打包好的程序直接运行；想从源码跑才需要 pip install -r requirements.txt。

道具列表不全？

收录的是游戏内绝大部分常见道具。缺什么去仓库提 Issue，说明名字和用途即可。
